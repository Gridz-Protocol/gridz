# gridz (Python)

Python core for [Gridz](../../README.md) — JCS canonicalization, EIP-712, merkle
roots, signers, and the universal verifier. Byte-for-byte cross-runtime
compatible with `@gridz/core`: a Grid signed in TypeScript verifies here, and a
Grid signed here verifies in TypeScript.

```bash
uv sync --extra dev
uv run pytest
```
