# Verification

Any consumer can verify a Grid with only `@gridz/core` (or Python `gridz`) and a
public RPC. No sink, server, or vault is trusted.

```ts
import { verifyGrid } from "@gridz/core";

const result = await verifyGrid(grid);
// { ok, cells: [{ id, key, result: { status } }], root: { status } }
```

Each cell resolves to one of:

| Status | Badge | Meaning |
|---|---|---|
| `verified` | ✓ green (🔑 for HSM) | signature valid, attester authorized, in time bounds |
| `expired` | ⚠ amber | past `expires_at` / attestation `exp` |
| `failed` | ✗ red | value tampered, bad signature, or unauthorized signer |
| `unsupported` | ⚠ amber | format can't be verified locally (e.g. bare on-chain ref) |

The verifier, in order: recomputes `value_hash` from the canonical value, recovers
the signer and checks it against the attester DID, checks authorization, checks
time bounds, then revocation. Steps 1–2 touch no network. The root attestation
additionally commits to the sorted merkle root of cell UIDs, so a dropped cell is
detectable.

Cross-runtime: a Grid signed in TypeScript verifies in Python and vice versa — and
the two produce byte-identical EIP-712 signatures.
