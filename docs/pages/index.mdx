# Gridz

An open framework for **cryptographically-attested social graphs** that work for
humans, AI agents, and organizations.

A **Grid** is a profile built from typed, signed fields — "cells". Each cell
carries a verifiable attestation, so anyone can prove *who said what, when, and
under which key*. Impersonation and DNS-style hijacks are defeated by design: a
consumer with only `(grid_id, public_key, attestation)` can verify a cell with no
server, sink, or vault in the loop.

## Why

- **Multi-modal** — one model for people, agents, and orgs. ENS profiles are valid
  minimal Grids; AI agents get ENSIP-26 endpoints and ERC-8004 identity.
- **Verifiable, not trusted** — sinks (ENS, Postgres, S3, …) are projections that
  can be rebuilt. The signed attestation is the source of truth.
- **Bring your own identity** — local wallets, passkeys, or a 1claw HSM. Gridz
  never custodies a key.
- **Same surface everywhere** — TypeScript and Python, byte-for-byte compatible.
