# Grid schema

The canonical JSON Schema (draft 2020-12) is
[`specs/grid.schema.json`](https://github.com/Spritz-Labs/gridz/blob/main/specs/grid.schema.json).
SDKs, the CLI, the server, and config authoring all validate against it.

```ts
interface Grid {
  schema_version: "gridz/1.0.0";
  subject: Subject;     // type, did, optional ens/sns/display_name
  theme: Theme;         // background, accent, card style, font, badge
  cells: Cell[];        // each: key, value, position, size, attestation
  root_attestation: AttestationRef; // signs the merkle root of cell UIDs
}
```

See [`specs/attestation.schema.json`](https://github.com/Spritz-Labs/gridz/blob/main/specs/attestation.schema.json)
for the attestation envelope.
