# Standard keys

The full registry is [`specs/standard-keys.md`](https://github.com/Spritz-Labs/gridz/blob/main/specs/standard-keys.md).
Three tiers:

1. **Inherited from ENS** — ENSIP-5/18 global + profile keys (`alias`,
   `description`, `avatar`, `url`, …) and reverse-dot service keys (`com.github`,
   `org.telegram`, …). Any ENS profile is a valid minimal Grid.
2. **Agent keys** — `agent-context`, `agent-endpoint[mcp|a2a|web]` (ENSIP-26),
   `agent-registration[<registry>][<agentId>]` (ENSIP-25), and the Gridz-namespaced
   `agent.capabilities` / `agent.model` / `agent.oneclaw_id`.
3. **Widget keys** — `gridz.*` (poll, clock, stats, social_link, …) each with a
   value schema and a renderer; unknown widget types fall back to Generic.

Dynamic keys are first-class: any key matching
`^[a-z0-9]([a-z0-9._\-\[\]])*[a-z0-9\]]$` round-trips losslessly.
