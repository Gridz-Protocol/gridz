# Canonicalization

Verification only works if every runtime hashes the same bytes. The normative
rules are [`specs/canonicalization.md`](https://github.com/Spritz-Labs/gridz/blob/main/specs/canonicalization.md):

- **JCS (RFC 8785)** canonical JSON before hashing.
- **keccak256** on EVM (did:pkh:eip155, EAS), **sha256** off-EVM (did:key,
  did:pkh:solana). The domain is fixed by the attestation `format`.
- `value_hash = H(JCS(cell.value))`; `gridId = H(JCS({did, schema_version}))`.
- The root signs a **sorted-pair merkle root** (OpenZeppelin-compatible) over cell
  attestation UIDs, so verifying one cell never requires the others, and a dropped
  cell is detectable via `cellCount`.

Big integers are encoded as strings, never JSON numbers.
