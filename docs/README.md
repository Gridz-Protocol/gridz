# Gridz docs

The documentation site, built with [Vocs](https://vocs.dev) and published to
**gridz.dev**. Standalone — not part of the monorepo install.

```bash
cd docs
pnpm install
pnpm dev      # local preview
pnpm build    # static output for gridz.dev
```

Content lives in `pages/`. Reference pages link back to the canonical `specs/`.
